# Interactive-Museum

Интерактивный музей как teamLab, но видеоигра, поэтому интерактива сильно больше

Godot 4.4. Проект Godot лежит в `interactive-museum/`: открыть `interactive-museum/project.godot` в редакторе, запуск F5.

- Дизайн: [docs/GDD.md](docs/GDD.md), решения в [docs/DESIGN.md](docs/DESIGN.md), спеки в [docs/specs/](docs/specs/)
- Процесс работы: [gamedev-hub/WORKFLOW.md](https://github.com/artemiiShabanov/gamedev-hub/blob/main/WORKFLOW.md)
